# 小说推广漫画 Codex Skill

将用户提供的中文小说改编为手机竖屏推广漫画。这个 skill 指导 Codex 先完成逐页脚本，再制作角色参考、分格画面、中文气泡台词和整套图片，并按页归档与质检。

适用于需要**封面＋多页漫画**的小说推广任务。新故事默认 **40～50 张，含封面**；用户当次指定的页数、标题和画风优先。仓库附有《偏爱真诚人》的 Q 版样图与版式规范，作为视觉参考。

## 使用方式

将本仓库克隆到 Codex 的 skills 目录：

```powershell
git clone https://github.com/CYU1102/novel-comic-promo.git "$HOME\.codex\skills\novel-comic-promo"
```

之后在任务中调用：

```text
$novel-comic-promo 用我上传的小说制作手机竖屏 Q 版推广漫画。先整理完整逐页脚本，再制作图片。
```

制作时可指定总张数、标题、尺寸、参考画风和结尾悬念。默认采用简约清爽的 Q 版大头短肢人物、自然易读的中文文字；左上角的**连续编号＋作品名融入背景**，不另开白底框。对白气泡依语气变化为椭圆、圆角或柔和云朵感，心声、旁白和音效使用各自适合的文字框，避免遮挡人物与关键动作。
