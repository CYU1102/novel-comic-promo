# 角色视觉记忆

用于多页人物、服装或场景出现漂移时，也用于开始新漫画前建立最小可用的角色参考。

为主要角色保存稳定的名字或编号、面部特征、发型、体型、服装、配色和标志物，并关联实际参考图片。优先复用用户给出的参考图或已经接受的成品页。缺少关键视角时再补正脸、全身、表情或动作参考；不必为了填满模板而给每个配角生成全套五种参考图。

把持续的外观变化记录为单独版本，例如常服与宗门服、受伤前后、年龄阶段。新版本保留人物的身份特征，并写清变化点。逐页脚本引用角色及版本；出图时把相关图片真正提供给图像生成工具，仅写文件路径不足以作为视觉参考。

出图后检查同一角色在格内、页间是否保持脸型、发型、服装、饰物和体型；场景中的门、灶台、桌位等方位是否接续。合格的新画面可以补充到参考图库，供后续页面复用。

方法参考：[Agent Mangaka Forge 的 img-memory 工作流](https://github.com/RemiPelloux/agent-mangaka-forge/blob/main/skills/generatemangapage/SKILL.md)。这里采用按角色和版本保存参考的做法，参考图数量由实际需要决定；台词仍以本 skill 的逐页脚本为准。
