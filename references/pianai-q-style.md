# 《偏爱真诚人》当前 Q 版视觉规范

用于继续《偏爱真诚人》推广漫画；当前有封面和前三页样图。整套制作目标为 **90～100 张（封面计入总数）**，以逐页脚本确定准确张数，左上角从封面 01 连续编号到末页。若用户改变风格、尺寸或页数，以新要求为准。参考图均随 skill 提供：[四图总览](../assets/pianai-q-v7-preview.jpg)、[封面](../assets/pianai-q-v7/cover.png)、[第1页](../assets/pianai-q-v7/page-01.png)、[第2页](../assets/pianai-q-v7/page-02.png)、[第3页](../assets/pianai-q-v7/page-03.png)。这些图用于角色与视觉节奏参照，不逐格照搬。

## 剧情与表达

- 按用户小说核对具体事件：相府千金嫁清贫举子周逸；婚后第三年周逸带有孕的柳月娥上门；晚膳下泻药，茅厕门外撒黄豆；周逸踩豆跌伤昏迷；柳月娥跪求见他，丫鬟报“手指动了”。不要把黄豆滑倒画成雨水或湿地打滑。
- Q 版人物以脸、眼神、动作说明关系，减少仅靠长旁白交代。欢喜、讽刺、失态、悬念应在相邻格的表情与景别中发生变化。
- 拆格跟随动作和信息转折：可用窄白斜栏、左右小格、上下不等高格、整幅主画面加局部小窗；某页也可完全不分格。不要为了凑格数而平均切割。

## 版式与文字

- 成品维持 1080×1620（2:3）竖图，左右铺满。页内只加窄白外边与窄白分栏，辅以细墨线；上下留白交给平台查看器，不把黑白条烘焙进图片。
- 左上角放不抢眼的“顺序编号＋作品名”，直接融入画面背景或原有留白，不单开白底框。根据背景选用对比清楚的字色、轻微描边或阴影，确保手机尺寸可读且不压人物、气泡和关键动作；此规则优先于旧样图中的白框角标。封面大标题清晰、有冲突感，但高亮和描边不牺牲可读性。偶尔一页可加一处很淡的作品名识别字样，不盖住画面信息。
- 所有文字框保持纯白、不透明、深色轮廓与深色中文。剧情旁白可用**紧凑长方形框**，人物对白用带尾巴的椭圆气泡，心声用思考气泡，急报或拟声用爆炸框；也可在需要软化语气时使用椭圆旁白。形状随表达目的变化，大小随字数与可用留白变化，不要求每页同量同尺寸。
- 文字量可以足，但拆成自然阅读的短句。框不能压人物五官、眼神、关键手势或黄豆等线索；在手机尺寸下逐页检查可读性。准确中文字宜用可控排版叠加，图像底图不预先生成文字。
- 喜庆婚礼用暖红，室内谈判用克制暖光，跌倒夜景用冷蓝与局部灯光，府门求见用清晰日光。表情和动作承担剧情的页保持背景简洁，关键转折才增加光影与动势；不把每页都画得华丽。

制作新页前先写“本页新增信息—情绪变化—翻页点”，再决定是否分格、用哪种文字框。修改样图时保留旧版文件；只有用户确认后才称为最终版。
