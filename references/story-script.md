# 剧情与逐页脚本

用于从小说生成或修改整套漫画脚本。先找出不可遗漏的事件、人物动机、关系变化、伏笔与揭示；为每个重要点记录可回查的原文段落或章节。为画面清晰而新增的过渡，应标记为改编补充，不冒充原著事实。

逐页记录以下内容，格式可用表格、Markdown 或 JSON，以方便实际制作和返工为准：

- 页码、这一页的剧情作用、对应原文情节点。
- 读者在翻到本页前已知什么、本页新知道什么、翻页时还想知道什么。
- 每格的场景、角色、动作、表情、镜头距离、阅读顺序；相邻格与前后页的动作衔接。
- 每句准确台词、说话者、旁白、音效字，以及它们应落在画面中的大致安全区。
- 本页使用的人物/服装/场景/道具参考图；缺失时需要补哪张。

写完后对照原文检查因果：角色为什么做这件事、重要信息何时被读者得知、悬念是否有铺垫。用户指定固定页数时，先保住必要剧情，再通过画面、反应和台词密度调整节奏；不要擅自增加页数或删掉关键动机。结尾页应停在具体未解的问题或即将发生的行动，而不只是写“未完待续”。

方法参考：[Novel-to-Comic Studio 的逐页故事与脚本流程](https://github.com/lhfer/codex-novel-to-comic-studio/blob/main/SKILL.md)。本文件只借鉴其可回查的剧情规划思想，不采用其默认尺寸、审批关卡或整页自动生字规则。
